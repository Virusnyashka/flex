# Моя зарплата Flex

Календарь рабочих смен с расчётом месячной зарплаты по правилам «Оплата рабочего времени».

**Открыть:** https://virusnyashka.github.io/flex/ — на iPhone: Safari → «Поделиться» → «На экран Домой».
Работает без интернета; данные хранятся только на устройстве (есть резервная копия в кабинете).

- **Календарь** — нажмите на день, выберите тип смены (утро, ночь, пятница, исход субботы),
  время начала/конца и перерыв. Сразу видно, сколько часов пойдёт по какому проценту.
- **Кабинет** — имя, часовая ставка, валюта, перерыв утренней смены по умолчанию;
  отчёт за месяц: зарплата, часы по процентам, выполнение нормы 42 ч по неделям, список смен.

Данные хранятся локально на устройстве (`shared_preferences`).

Логика расчёта — `lib/logic/pay_calculator.dart`, тесты — `test/pay_calculator_test.dart`.

```bash
flutter test
flutter run
tool/build_pwa.sh       # офлайн веб-версия в build/web
tool/deploy_pages.sh    # сборка и публикация на GitHub Pages
```
